# 六大行客户经营分析项目 · 从零到一

> 这篇写给非技术背景的自己：不讲代码细节，讲每一步为什么这么做、怎么向面试官说。

## 一、为什么做这个项目

投六大行客户经理岗时，最怕面试官问两个问题：

1. 你懂不懂银行业务？
2. 你能不能让客户愿意把钱留在你这里？

简历只能证明“我会销售、会运营”，但这个项目能补上“我理解银行零售业务怎么赚钱、客户经理每天做什么”。

## 二、项目分了几步

| 步骤 | 做了什么 | 面试怎么说 |
|---|---|---|
| 1 | 收集六大行 2025 年报数据 | “我从官方年报和权威财经媒体交叉核对” |
| 2 | 整理个人客户、AUM、利润等指标 | “我关心规模，也关心利润质量” |
| 3 | 发现“AUM全增长、利润分化” | “规模增长不等于利润做优” |
| 4 | 生成 5 万行模拟客户表 | “我用 SQL 生成学习用数据，不碰真实客户” |
| 5 | 写 4 条分析 SQL | “把客户经理的工作变成可复现的逻辑” |
| 6 | 做网页、PDF、PPT | “我能把行业判断和执行动作都讲出来” |

## 三、模拟客户表是怎么来的

我们先生成 50,000 个客户号，再给每个客户分配这些字段：

- 所在城市
- 开户渠道（柜台、代发工资、线上活动、手机银行）
- AUM（放在本行的钱）
- 持有产品数
- 月均交易笔数
- 近 90 天活跃天数

为了让数据“像真实银行”，我们用了一个小技巧：

- 把客户按 AUM 分成 4 档：高价值、成长、基础、低价值
- 高价值客户约 2%，但贡献约 40% 的 AUM
- 成长客户占 18%，贡献约 41% 的 AUM
- 前 20% 客户加起来贡献约 80% 的 AUM

面试时不需要讲公式，只需要说：

> “我按客户价值分层，发现资源高度集中在少数高价值客户身上，所以客户经理不能平均用力。”

## 四、4 条 SQL 分别证明什么

### Q1：客户分档

把 AUM 切成 4 档，看每档客户数和贡献。

结论：高价值客户少但 AUM 大，客户经理要先识别“把时间花给谁”。

### Q2：交叉销售

找“资产不错但产品少”的成长客户。

结论：有 2,996 位客户、对应 15.02 亿 AUM，是产品渗透的优先名单。

### Q3：渠道质量

按开户渠道看户均 AUM。

结论：代发工资客户户均最高，说明批量获客和薪资沉淀是高质量入口；手机银行客户需要运营唤醒。

### Q4：流失预警

用“低活跃 + 低交易 + 有资产”三个条件筛名单。

结论：有 192 位客户需要优先触达，先唤醒沉默客户比新拓客成本更低。

## 五、面试 30 秒版

> “我分析了六大行年报，发现零售 AUM 全线增长但利润分化；再用模拟客户表做 SQL 分层，证明客户经理是通过客户分层、交叉销售、渠道经营和流失预警来提升经营质量，而不是单纯拉存款。”

## 六、项目真实性边界

- 年报数字：真实，来源已标注。
- 模拟客户表：不是真实客户，仅用于演示分析方法。
- SQL：真实可运行，使用 SQLite 打开 `output/customers.db` 即可复现。
- 如果面试官问“数据是不是编的”，回答：真实年报负责行业判断，模拟表负责展示方法，边界写得很清楚。

## 七、后续还能怎么升级

1. 加城市维度分析，匹配杭州、深圳、西安。
2. 加 RFM 模型，把分层讲得更专业。
3. 用 Excel 透视表重做一遍，展示“Excel 能做的我也懂”。
4. 针对某一家目标银行做深读，比如邮储的县域客群。
