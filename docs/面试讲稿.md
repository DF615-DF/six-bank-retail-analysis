# 六大行客户经营分析项目 · 面试讲稿

## 1. 两分钟完整版

“我针对银行客户经理岗做了一个六大行客户经营分析项目。

第一步，我从工、农、中、建、交、邮储 2025 年年报和官方业绩发布中，收集了个人客户数、零售 AUM、数字渠道和零售利润数据。
第二步，我发现一个值得讲的矛盾：六家银行零售 AUM 全部正增长，但零售利润分化很大，工行个人金融业务利润增长 43.62%，邮储却下降 47.35%。
第三步，我把行业结论落到客户经理动作上，用一张 5 万行模拟客户表做了 SQL 分层，识别出高价值客户只占 2% 但贡献约 39% AUM，成长客户是交叉销售主力，代发客户户均价值最高，低活跃客户需要流失预警。
最后我整理成网页报告、PPT 和面试讲稿，保证自己既能讲清行业，也能讲清执行。”

## 2. 一分钟精简版

“我做了六大行客户经营分析，核心结论是 AUM 越做越大，但利润质量分化。
我用真实年报数据证明行业判断，用模拟客户表做 SQL 分层，说明客户经理不是单纯拉存款，而是做客户分层、交叉销售、渠道经营和流失预警的闭环。”

## 3. 常见追问

### 数据哪里来的？

各银行 2025 年年报和官方业绩发布，以及证券时报、21 世纪经济报道、中国证券报的年报汇总。
涉及口径不同处，我在报告里标注了“约、超、媒体口径”。

### 为什么选择这六个指标？

个人客户数看广度，零售 AUM 看深度，AUM 增速看趋势，数字渠道看触达能力，零售利润看质量，不良率看风险。
客户经理既要会服务，也要懂风险。

### SQL 是不是你写的？

是 AI 辅助下边学边写。我能讲清每条语句的业务目的，包括 SELECT、CASE WHEN、GROUP BY、COUNT、SUM、AVG、WHERE、ORDER BY 和 LIMIT。
模拟客户表是学习用途，真实银行环境需要脱敏和合规审批。

### 如果入职后给你 1000 个客户，先做什么？

先看 AUM 分布，找出“高价值但产品少”和“活跃但资产低”两类名单；
高价值客户做面谈配置，成长客户做线上产品渗透，低活跃客户先唤醒，同时做好风险提示。

### 你觉得自己和这个岗位的匹配点？

联通陌拜证明我能触达大量客户并完成转化；百胜门店运营证明我能做成本、排班和标准化；这个项目证明我愿意学数据工具，也能把业务讲清楚。

## 4. 名词解释（面试备用）

- AUM：客户放在本行的金融资产合计，通常包括存款、理财、基金、保险、贵金属等。
- 钱包份额：客户全部金融资产中，放在本行的比例。
- 交叉销售：让同一客户从持有 1 类产品增加到 2-3 类产品。
- 流失预警：用活跃度、交易频率、资产变化等信号，提前识别可能离开的客户。
- 净息差：银行净利息收入除以平均生息资产，衡量“存贷利差”赚钱能力。
