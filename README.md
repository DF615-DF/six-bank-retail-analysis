# 六大行客户经营分析项目

> 飞土木作品集 · 面向银行客户经理/零售岗的求职项目

## 一句话介绍

用六大国有银行 2025 年年报的真实数据，说明“零售 AUM 全线增长，但零售利润普遍承压”，
再用一个 5 万行模拟客户表的 SQL 案例，把客户经理的日常工作翻译成“客户分层、交叉销售、渠道质量、流失预警”四步闭环。

## 核心数据结论

1. 2025 年末六大行零售 AUM 全部正增长，工行 25.37 万亿、农行 24.68 万亿、建行 23.01 万亿位居前三。
2. 零售利润明显分化：工行个人金融业务利润同比 +43.62%，邮储 -47.35%，交行 -35.76%，说明规模增长不等于利润质量。
3. 客户经理岗位的价值不是“拉存款”，而是通过客户分层、钱包份额提升、交叉销售、数字触达和风险合规做经营闭环。

## 使用方式

- 网页版：直接双击 `index.html`，或部署到作品集静态托管。
- PDF：`docs/六大行客户经营分析报告.pdf`，适合面试留档。
- PPT：`assets/六大行客户经营分析汇报.pptx`，适合面试讲解。
- SQL：按 `sql/README.md` 用本机 SQLite 重新生成和查询。

## 数据来源

各银行 2025 年度报告/官方业绩发布；证券时报、21 世纪经济报道、中国证券报等对年报数据的汇总。
完整来源清单在 `index.html` 底部和知识库项目笔记中。

## 面试要点

- 不背代码，讲“为什么做、数据怎么来、结论是什么、对客户经理有什么用”。
- 真实年报负责行业判断，模拟 SQL 负责经营动作。
- 模拟数据明确标注为学习用途，不冒充真实客户数据。
